# AI Career Success Advisor
### A Full-Stack ML + Generative AI Platform for Student Career Intelligence

**Live Demo:** [ai-career-success-advisor-production.up.railway.app](https://ai-career-success-advisor-production.up.railway.app)

## Executive Summary

AI Career Success Advisor is a full-stack web application that combines two trained machine learning models with Google's Gemini 2.5 Flash generative model to give students a structured, data-driven view of their career readiness. A student enters their academic and activity profile — CGPA, attendance, scores, projects, internships, and more — and the system returns a predicted academic category, an employability score, a placement probability, and a set of identified strengths and weaknesses. From that single prediction, the platform branches into four connected tools: an AI-generated 30-day career roadmap, a Gemini-powered resume ATS analyzer, role-matched learning resources, and a context-aware career chatbot. The application is deployed on Railway with Firebase handling authentication and session persistence.

---

## Problem Statement

Most students preparing for placements face the same three gaps:

1. **No objective benchmark.** CGPA and attendance alone don't tell a student how employable they actually are, or where they stand relative to their target role.
2. **Fragmented resources.** Resume feedback, DSA prep, interview questions, and course recommendations are scattered across dozens of unrelated sites, with no single view of what to do next.
3. **Generic advice.** Most resume checkers and career tools give the same templated feedback regardless of a student's actual background, goal, or weak areas.

AI Career Success Advisor was built to close these gaps in one connected workflow — from raw profile data to a specific, prioritized action plan.

---

## Objectives

- Predict a student's academic category and employability score using trained ML models rather than static rule-of-thumb thresholds.
- Convert a prediction into a concrete, personalized 30-day learning roadmap rather than generic advice.
- Give students an ATS-style review of their actual resume, not a generic checklist.
- Surface curated learning resources matched to the student's specific target role.
- Wrap all of the above in a single authenticated, persistent experience a student can return to across sessions.

---

## Solution

The application is a Flask-based single-page experience backed by two components:

- **A machine learning layer** — a Random Forest Classifier and a Random Forest Regressor, trained on a 28-feature student profile dataset, that produce the academic category, employability score, and placement probability.
- **A generative AI layer** — three independent modules (`mentor.py`, `chat.py`, `resume_analyzer.py`) that each call Google Gemini 2.5 Flash for a specific task: roadmap generation, conversational career guidance, and resume analysis.

Firebase Authentication handles login (email/password and Google OAuth), and Firestore persists the student's hero dashboard state (confidence score, profile signals, recommendation count) between sessions. The result is a workflow that starts with hard numbers from a trained model and ends with specific, actionable next steps generated by an LLM that has that model's output as context.

## Key Features

### 🎯 Career Prediction System
Predicts academic category (Excellent / Good / Average / At Risk), an employability score out of 100, and a placement probability percentage, alongside automatically identified strengths, weaknesses, and recommendations. Supports 6 degrees, multiple branches, 3 career goals, 6 target roles, and 2 sectors.

### 🤖 AI Mentor — 30-Day Roadmap Generator
Reads the student's full prediction result and generates a structured, week-by-week 30-day roadmap — each week including a goal, topics to cover, hands-on tasks, projects to build, learning resources, and interview preparation tips.

### 📄 Resume Analyzer
Accepts PDF resume uploads (up to 10 MB), extracts the text with PyPDF2, and sends it to Gemini for a structured ATS-style review across seven sections: ATS Score, Strengths, Weaknesses, Missing Skills, Projects Review, Resume Formatting, and Interview Readiness — plus Final Suggestions. Upload progress is tracked with a real XHR-based progress bar.

### 💬 AI Career Chatbot
A floating widget, context-aware of the student's prediction results (target role, scores, weaknesses) when available. It supports quick-action cards (Analyze Resume, Generate Roadmap, Mock Interview, DSA Planner, GitHub Review, LinkedIn Review, and more), Markdown-rendered responses, voice input via the Web Speech API, text-to-speech playback, chat export to `.txt`, and per-message copy/like/dislike/retry/speak actions.

### 📚 Personalized Career Resources
Loaded dynamically from `career_resources.json` via `GET /api/resources/<role>`, matched to the student's selected target role, and organized into six categories: Courses, Certifications, Roadmaps, YouTube Channels, Practice Platforms, and Books. Each card shows difficulty level, time estimate, source, and a direct link.

### 📦 Downloadable Resources
Six static, ready-to-use files: a sample resume, five editable resume templates, a DSA sheet, SQL placement notes, an interview question bank, and GitHub README templates.

### 🔐 Authentication
Firebase-backed email/password sign-up and login, Google OAuth one-click login, forgot-password email reset, a password strength meter, and persistent login state reflected live in the navbar.

### 🎨 UI/UX
Dark and light themes with localStorage persistence, an animated neural network canvas background, a glassmorphism card design system, scroll-reveal animations, animated circular score gauges, animated number counters, and a step-by-step AI progress overlay during prediction — all fully responsive across desktop, tablet, and mobile.

## AI & Machine Learning Pipeline

The prediction pipeline takes in **28 student profile features** across five categories — Academic (degree, branch, year, CGPA, attendance, backlogs), Study Habits (study hours, self-learning hours, sleep hours, screen time), Scores (assignment, internal marks, programming, SQL, DSA, communication, aptitude, resume, ATS), Activity (projects, hackathons, certifications, internships, GitHub activity, LinkedIn activity), and Career Goal (goal, target role, sector).

```
Raw Form Input
      │
      ▼
Label Encoding (degree, branch, goal, target_role, sector)
      │
      ▼
Random Forest Classifier → Academic Category (Excellent / Good / Average / At Risk)
      │
      ▼
Academic Score Calculation
(CGPA × 7 + study_hours × 3 + self_learning × 2 + projects × 2 + attendance × 0.05 − backlogs × 8 − screen_time)
      │
      ▼
Random Forest Regressor → Employability Score (0–100)
      │
      ▼
Placement Probability = min(employability_score × 0.90, 100)
      │
      ▼
Rule-based Strengths & Weaknesses Detection
      │
      ▼
Recommendation Generation
```

| Model | Algorithm | Task | Metric |
|---|---|---|---|
| Academic Model | Random Forest Classifier | Predict academic category | Accuracy: **83.2%** |
| Employability Model | Random Forest Regressor | Predict employability score | R² Score: **0.97** |

Both models are trained offline (`train_academic_model.py`, `train_employability_model.py`) on a dedicated dataset (`dataset/datasetv5.csv`), serialized with Joblib, and loaded by the Flask app at request time — keeping inference fast and independent of the generative AI layer.

## Google Gemini AI Integration

The application uses the `google-genai` Python SDK with the `gemini-2.5-flash` model across three independent, purpose-built modules:

**`mentor.py` — AI Roadmap Generator**
Receives the full student profile (degree, branch, CGPA, academic category, employability score, placement probability, target role, goal, strengths, weaknesses, recommendations) and instructs Gemini to return a strict JSON schema of four weekly roadmap objects, each containing a title, goal, topics, tasks, projects, resources, and interview preparation guidance.

**`chat.py` — AI Career Chatbot**
Uses the student's live prediction context as a system prompt prefix when available, handles simple greetings with hardcoded fast responses to save API calls, and passes complex questions to Gemini along with the student's full profile so responses stay personalized to their target role and weak areas.

**`resume_analyzer.py` — Resume ATS Reviewer**
Extracts text from the uploaded PDF with PyPDF2, sends it to Gemini with a structured prompt requesting seven analysis sections, and the frontend parses the response into distinct cards for score, strengths, weaknesses, and recommendations.

## Resume Analyzer

Students drag and drop a PDF resume (up to 10 MB). The file is uploaded via XHR with a real, tracked progress bar, text is extracted server-side with PyPDF2, and the raw content is passed to Gemini for review. The response is rendered as an animated ATS score gauge alongside seven structured cards: Strengths, Weaknesses, Missing Skills, Projects Review, Resume Formatting, Interview Readiness, and Final Suggestions.

## Career Prediction System

This is the entry point of the platform. A two-tab form — Student Performance (slider-based) and Career Success (counters and dropdowns) — feeds all 28 features into the ML pipeline in a single pass. Results are displayed as an academic category badge, an employability gauge, a placement probability bar, tagged strengths and weaknesses, and a list of personalized recommendations — all of which become the context for every downstream feature (roadmap, chatbot, resources).

Each week includes a title and goal, topics to study, hands-on tasks, a project to build, resources to use, and interview preparation tips specific to that week's focus — turning a single prediction into a concrete, sequenced study plan rather than a one-off score.

## Authentication System

Authentication runs entirely client-side through the Firebase Web SDK v12 (`firebase.js`, `login.js`):

| Feature | Implementation |
|---|---|
| Email sign-up | `createUserWithEmailAndPassword` |
| Email login | `signInWithEmailAndPassword` |
| Google OAuth | `signInWithPopup` with `GoogleAuthProvider` |
| Password reset | `sendPasswordResetEmail` |
| Session state | `onAuthStateChanged` listener in `script.js` |
| User data persistence | Firestore `users/{uid}` document |
| Logout | `signOut` → redirect to `/login` |

After login, the navbar Login button switches to Logout in real time, and the hero dashboard state (confidence percentage, profile signals, recommendation count) is saved to Firestore and restored on the student's next visit.

## Challenges Faced

- **Keeping two prediction models numerically consistent.** The classifier and regressor are trained separately but need to produce results that read as one coherent profile (e.g., an "Excellent" academic category shouldn't ever pair with a contradictory low employability score). This was addressed with the deterministic academic score formula that feeds into the regressor, keeping both outputs anchored to the same underlying signals.
- **Making Gemini output structured, not conversational.** Free-form LLM responses don't map cleanly onto UI cards. `mentor.py` and `resume_analyzer.py` both required carefully constrained prompts — a strict JSON schema for the roadmap, and a fixed seven-section structure for resume feedback — so the frontend could reliably parse and render the output.
- **Balancing chatbot cost and responsiveness.** Routing every message through Gemini would add latency and API cost even for simple exchanges, so `chat.py` short-circuits common greetings with hardcoded responses and reserves the full model call — with the student's profile as context — for substantive questions.
- **Session state that survives a refresh.** Persisting the hero dashboard (confidence score, profile signals, recommendation count) required wiring Firestore reads/writes into the existing Firebase Auth flow so a student's last result is still there when they come back.

---

## Engineering Decisions

- **Two specialized models instead of one.** A classifier for the categorical academic outcome and a separate regressor for the continuous employability score, rather than forcing both into a single model — each algorithm matches the shape of its target variable.
- **Separating ML inference from generative AI.** The `/predict` route never calls Gemini, and the Gemini-backed routes never touch the trained models directly — they only consume the prediction's JSON output. This keeps the fast, deterministic ML path independent of external API latency.
- **One Gemini module per responsibility.** `mentor.py`, `chat.py`, and `resume_analyzer.py` are separate files with separate prompts, rather than one shared "AI handler" — making each easier to prompt-tune and debug in isolation.
- **Client-side Firebase Authentication.** Using the Firebase Web SDK directly from the frontend (rather than proxying auth through Flask) reduces backend surface area and relies on Firebase's own security rules for Firestore access.
- **Static JSON for resources instead of a database.** `career_resources.json` and `career_data.json` are flat files rather than database tables — appropriate for content that changes infrequently and doesn't need querying beyond a simple role lookup.

## Key Learnings

- Designing a 28-feature input schema end-to-end — from form UI, to label encoding, to model training — clarified how much upfront data modeling shapes everything downstream, including what the LLM layer can meaningfully personalize.
- Prompt design for structured output (strict JSON schemas, fixed section counts) is a different skill from conversational prompting, and getting it wrong breaks the UI, not just the response quality.
- Splitting a fast, deterministic ML path from a slower, external generative AI path is a pattern worth defaulting to any time both are present in the same product — it keeps core functionality available even if one dependency is slow or rate-limited.
- Firebase's client-side auth model shifts real architectural decisions (where session state lives, how it's restored) onto the frontend in a way that's easy to underestimate until you're building persistence across page reloads.

## Conclusion

AI Career Success Advisor demonstrates a complete, production-deployed workflow that combines classical machine learning with generative AI in clearly separated, purpose-built layers — a trained Random Forest pipeline for objective scoring, and three independent Gemini-backed modules for roadmap generation, resume analysis, and conversational guidance. Built and deployed end-to-end, from dataset and model training through Firebase authentication to a live Railway deployment, it reflects a full-stack, product-minded approach to applying AI to a real, well-defined student problem.
